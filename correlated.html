Reading this bench

When features move together, a hidden one still counts, at whatever weight the human believes it has.

Guan, Raman and Fang (2026) show that once features are correlated, showing the same subset every round can be arbitrarily worse than the best policy, which explores first and then commits. This bench carries their model over to picking the best of several actions.

The human sees only the shown features xS and fills in the rest with what they predict, E[xhidden | xS] = ΣhS ΣSS−1 xS, then picks argmaxk (H x̂)k. Because the filled-in state is a fixed matrix times the true one, x̂ = PS x, the human acts as if their weights were H PS (Fig. 8).

As in the paper, a weight is learned only on the rounds its feature is shown. A filled-in value never corrects the belief about that feature, so a misjudged hidden feature keeps pulling the choice the wrong way. With independent features it would be filled in as zero and simply drop out.

Exploring rotates through every subset of the budgeted size, so each feature is shown equally often. Then the algorithm commits to one subset for good. Exploring 0 rounds is the fixed-subset policy of Noti et al.

The ranking runs every fixed subset and every explore-then-commit policy whose exploration is a whole number of rotations, up to 20 lengths. Unlike the paper's dynamic program, this search over one family is not guaranteed to find the true optimum. Click a row to put that policy on the bench.

Each round has its own state xt ~ N(0, Σ), and its regret is taken there. Every policy in the ranking is run on the same draw. The grey in the figures and the “averaged over states” numbers score each round over 2,000 probe states instead. Both use the same standard normals as the independent bench, so with Σ = I this page gives that bench's numbers.

Fig. 7 rings the probe states where the human's pick is not the best move. The dashed line is E[xj | xi] = ρij xi, the value the human would fill in for the vertical feature from the horizontal one alone.
