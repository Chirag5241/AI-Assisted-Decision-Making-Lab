The two-action problem

A constrained version of the problem, with K = 2 actions and n ≥ 1 features. The algorithm 𝒜 shows all actions to the human ℋ and can only suggest features Ft of size c at each timestep t. This is the most direct extension of the Noti et al. problem with actions. To start with, we assume that 𝒜 has full view into everything: U, x(t) and H(t).

The setupWhen the human is correctWhat the algorithm must solve Loss and updateQuestions

The setup

At each timestep t.

The features

x(t) = x(t)1⋮x(t)n ∈ ℝn

The human's internal utility matrix

H(t) = — h(t)1 —— h(t)2 —

The ground truth utility matrix

U = — u1 —— u2 —

When the human is correct

The correct move

uTa x(t) ≥ uTa x(t)

Let a ∈ {1, 2} be the correct move, and a ∈ {1, 2} ∖ {a}. Since a is the correct move, this holds.

ℋ is correct on Ft

Σi ∈ Ft h(t)a,i · x(t)i > Σi ∈ Ft h(t)a,i · x(t)i

For a set Ft shown to ℋ at a t > 0, ℋ is correct if this holds.

What the algorithm must solve

A subset on which ℋ is correct

Σi ∈ Ft (h(t)a,i − h(t)a,i) · x(t)i > 0

Thus 𝒜 must solve the problem of finding a subset Ft with |Ft| < c for which this holds.

Every such subset

Ct = { Ft ⊆ [n] : |Ft| < c,
Σi ∈ Ft (h(t)a,i − h(t)a,i) · x(t)i > 0 }

By brute force, 𝒜 can find Ct in nk · k time.

Loss and update

The loss of a wrong round

uTa x(t) − uTa x(t)

When the human is wrong, and picks a, this is the loss for that round.

The update H(t) → H(t+1)

|uij − h(t+1)ij| = φj(t + 1) / φj(t) · |uij − h(t)ij|

mj(t) is the number of times feature j has been seen at time t, and φ(·) is a monotonic non-increasing function with φ(0) = 1. For each j ∈ Ft, this update is made to get h(t+1)ij, for each i ∈ [K].

On the benches the learning curve is written the other way up, as the share of the gap already closed (Eq. 4). Reading φj(t) as φ(mj(t)), one minus the benches' curve is √φ here.

Questions

  1. What does 𝒜 do when |Ct| = 0? What is best to suggest: the most diverted features, since the loss is fixed? Or some other?
  2. Which subset to show when |Ct| > 1? Any? A specific one?

What the bench does for now

State-aware subsets runs this search in every round, for any number of actions, over the subsets of at most C features. When Ct is empty it shows one of the candidates at random, as a stand-in. When Ct holds several, it prefers one on which the truth also ranks a first, and among those the one with the widest margin, or the one with the most features.
