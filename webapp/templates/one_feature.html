One feature a round

Two actions, one feature shown a round, x ~ N(0, I). The solution: show the feature with the largest sj = |dj| (2δτj − 1) every round, where τj is the number of showings before the human's belief takes the sign of dj.

Correlated features

x ~ N(0, Σ), the human still uses only the shown feature. Showing xj costs (√(dTΣd) − sgn(gj) (Σd)j) / √(2π): the right sign is that of (Σd)j, but learning takes gj to the sign of dj.

{{ world(study.broken) }}, correlation {{ study.broken.rho }}: Σd = {{ vec(study.broken.reach|map("round", 2)) }}. x₂ stands in for x₁, so the human's wrong belief about x₂ picks well, until they learn it.

Filling in the hidden features

As on the Correlated features bench: the human fills in x̂i = Σij xj and scores (Σg)j xj. Showing xj costs (√(dTΣd) − sgn((Σg)j) (Σd)j) / √(2π): it hangs on the beliefs about the hidden features, which showing xj never teaches.

{{ world(study.imputed) }}, correlation {{ study.imputed.rho }}. x₂ is backwards, so filling it in spoils x₁: x₁ every round is wrong forever.
