The two-action problem

A constrained version of the problem, with K = 2 actions and n ≥ 1 features. The algorithm {{ A }} shows all actions to the human {{ H }} and can only suggest features Ft of size c at each timestep t. This is the most direct extension of the Noti et al. problem with actions. To start with, we assume that {{ A }} has full view into everything: U, x(t) and H(t).

What the algorithm must solve

A subset on which {{ H }} is correct

{{ margin }} > 0

Thus {{ A }} must solve the problem of finding a subset Ft with |Ft| < c for which this holds.

Every such subset

Ct = { Ft ⊆ [n] : |Ft| < c,
{{ margin }} > 0 }

By brute force, {{ A }} can find Ct in nk · k time.

Loss and update

The loss of a wrong round

{{ u("a") }} x(t) − {{ u(abar) }} x(t)

When the human is wrong, and picks {{ abar }}, this is the loss for that round.

The update H(t) → H(t+1)

|uij − {{ h("ij", "(t+1)") }}| = φj(t + 1) / φj(t) · |uij − {{ h("ij") }}|

mj(t) is the number of times feature j has been seen at time t, and φ(·) is a monotonic non-increasing function with φ(0) = 1. For each j ∈ Ft, this update is made to get {{ h("ij", "(t+1)") }}, for each i ∈ [K].

On the benches the learning curve is written the other way up, as the share of the gap already closed (Eq. {{ equation["learning"].n }}). Reading φj(t) as φ(mj(t)), one minus the benches' curve is √φ here.

Questions

  1. What does {{ A }} do when |Ct| = 0? What is best to suggest: the most diverted features, since the loss is fixed? Or some other?
  2. Which subset to show when |Ct| > 1? Any? A specific one?

What the bench does for now

State-aware subsets runs this search in every round, for any number of actions, over the subsets of at most C features. When Ct is empty it shows one of the candidates at random, as a stand-in. When Ct holds several, it prefers one on which the truth also ranks a first, and among those the one with the widest margin, or the one with the most features.
