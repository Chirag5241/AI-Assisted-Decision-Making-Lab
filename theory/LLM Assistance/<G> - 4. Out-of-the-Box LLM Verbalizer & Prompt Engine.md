# <G> - 4. Out-of-the-Box LLM Verbalizer & Prompt Engine

This note details **Stage 2 of the Two-Stage Architecture**: translating the mathematical control tuple $M_t^* = (\alpha_t^*, a_t^*, \hat{k}_t^*)$ into natural language advice using an off-the-shelf LLM (Gemini, Claude, GPT-4) while steering text along the estimated latent preference vector $\hat{z}_t \in \mathbb{R}^p$ (derived in [[<G> - 6. Latent Preference Alignment & Online Learning]]).

---

### 1. The Verbalizer Architecture

The Stage 2 Verbalizer is a structured prompt wrapper that sits between the mathematical controller and the human user:

```
┌────────────────────────────────────────────────────────────────────────┐
│  STAGE 1: MATHEMATICAL CONTROLLER                                      │
│  Outputs optimal control tuple:                                        │
│    - Scaffolding degree:   α_t* ∈ [0, 1]                               │
│    - Attention saliency:   a_t* ∈ [0, 1]^n                             │
│    - Recommended action:   k_t* ∈ [K]                                  │
└────────────────────────────────────┬───────────────────────────────────┘
                                     │
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│  STAGE 2: STRUCTURED PROMPT COMPILER                                   │
│  Compiles control tuple + estimated latent preference vector ẑ_t:      │
│  {                                                                     │
│    "case_symptoms": s^(t),                                             │
│    "target_scaffolding": α_t*,                                         │
│    "focus_features": [names of features with high a_j*],               │
│    "optimal_action": k_t*,                                             │
│    "latent_steering": {                                                │
│        "conciseness_weight": ẑ_density,                                │
│        "struggle_tolerance": ẑ_friction,                               │

```

### 2. The Universal System Prompt Template

The following system prompt enforces the mathematical boundaries of $(\alpha, a, \hat{k})$ while steering text generation along the user's latent preference vector $\hat{z}$:

```markdown
You are an expert pedagogical tutor assisting a human decision-maker.
Your objective is to maximize long-term human skill acquisition while preventing catastrophic immediate errors.

You will receive:
1. `CASE_SYMPTOMS`: The observable baseline features (s).
2. `SCAFFOLDING_DEGREE` (α ∈ [0.0, 1.0]):
   - α ≥ 0.8 (DIRECTIVE MODE): Provide clear, authoritative guidance. Explicitly state the recommended action.
   - 0.3 ≤ α < 0.8 (GUIDED SCAFFOLDING): Nudge the user toward the recommended action, but do not dictate it. 
     Frame the decision around the focus features.
   - α < 0.3 (SOCRATIC MODE): DO NOT REVEAL THE RECOMMENDED ACTION UNDER ANY CIRCUMSTANCES. 
     Formulate a targeted Socratic inquiry directing the user's attention exclusively to the `FOCUS_FEATURES`.
3. `FOCUS_FEATURES`: The specific underlying features (a_j) that the user must mentally evaluate.
4. `RECOMMENDED_ACTION` (k*): The ground-truth optimal action.
5. `LATENT_STEERING_VECTOR` (ẑ):
   - Conciseness weight ẑ_1: If positive, enforce extreme brevity (≤ 2 sentences). If negative, provide structured elaboration.
   - Socratic tolerance ẑ_2: If negative, provide gentler structural analogies; if positive, pose direct challenging questions.
   - Tone weight ẑ_3: Continuum between clinical/formal and conversational/encouraging.

STRICT CONSTRAINTS:
- Never reveal the recommended action when α < 0.3.
- Do not mention other features outside `FOCUS_FEATURES`.
- Strictly adhere to the requested conciseness weight.
```

### 3. Concrete Execution Examples

We illustrate the prompt engine across the three operational modes on the **Spanish *Ser* vs. *Estar*** decision task:
* Action 1 ($k=1$): *Ser* (`es`)
* Action 2 ($k=2$): *Estar* (`está`)
* Ground Truth: Sentence is *"La comida está fría"* (The food is cold - temporary state $\implies k^* = 2$).
* Focus feature: $x_1$ = Transience / Temporary state ($a_{t, 1}^* = 1$).

#### Case 1: Socratic Mode ($\alpha_t^* = 0.0$, High Conciseness Preference $\hat{z}_1 > 0$)
* **Controller Output:** $\alpha_t^* = 0.0$, Focus = `['Temporary vs Inherent Quality']`, Recommended = `Estar`.
* **Compiled LLM Input:**
  ```json
  {
    "case": "La comida ______ fría.",
    "scaffolding_degree": 0.0,
    "focus_features": ["Temporary state vs permanent essence"],
    "recommended_action": "Estar",
    "latent_steering": { "conciseness": "+1.5", "tone": "direct" }
  }
  ```
* **LLM Generated Output:**
  > *"Consider whether the food being cold is an unchangeable identity of the dish, or just its temporary condition right now. Which verb reflects that distinction?"*
* **Mathematical Outcome:** User must engage their internal weights $H$. Learning engagement $g_{t, 1} = (1 - 0) \times 1 = 1$. Contraction is maximal.

---

#### Case 2: Guided Scaffolding Mode ($\alpha_t^* = 0.5$, Balanced Style $\hat{z}_1 \approx 0$)
* **Controller Output:** $\alpha_t^* = 0.5$, Focus = `['Temporary condition']`, Recommended = `Estar`.
* **Compiled LLM Input:**
  ```json
  {
    "case": "La comida ______ fría.",
    "scaffolding_degree": 0.5,
    "focus_features": ["Temporary condition"],
    "recommended_action": "Estar",
    "latent_steering": { "conciseness": "0.0", "tone": "balanced" }
  }
  ```
* **LLM Generated Output:**
  > *"Notice that temperature is a fluctuating physical condition, not a permanent definition of the food. Verbs denoting current states typically pair with 'estar'. Take a moment to verify before choosing."*
* **Mathematical Outcome:** The user is steered away from error while still verifying the grammatical rule. Learning engagement $g_{t, 1} = (1 - 0.5) \times 1 = 0.5$.

---

#### Case 3: Directive Shield Mode ($\alpha_t^* = 1.0$, Concise Style $\hat{z}_1 > 0$)
* **Controller Output:** $\alpha_t^* = 1.0$, Focus = `['Temporary condition']`, Recommended = `Estar`.
* **Compiled LLM Input:**
  ```json
  {
    "case": "La comida ______ fría.",
    "scaffolding_degree": 1.0,
    "focus_features": ["Temporary condition"],
    "recommended_action": "Estar",
    "latent_steering": { "conciseness": "+1.8", "tone": "direct" }
  }
  ```
* **LLM Generated Output:**
  > *"Use 'está'. Temperature in food describes a temporary state, requiring 'estar'."*
* **Mathematical Outcome:** Immediate decision error is 0. Learning engagement $g_{t, 1} = 0$. (Used when training mistake penalty $\lambda \Delta_{\text{reg}}$ is high).

### 4. Summary of System Benefits

1. **Immunity to Sycophancy:** Because the mathematical controller strictly enforces $\alpha_t^* < 0.3$ on teachable cases, the LLM is barred from giving away the answer, overcoming the default RLHF helpfulness trap.
2. **Personalized Cognitive Comfort via $\hat{z}_t$:** The prompt steers text to match the user's latent preference profile without altering the mathematical control tuple $(\alpha_t^*, a_t^*, \hat{k}_t^*)$.
3. **Seamless Graduation:** When $t > \tau$, the controller simply disengages the verbalizer entirely. The user transitions naturally to unassisted practice without software disruption.
