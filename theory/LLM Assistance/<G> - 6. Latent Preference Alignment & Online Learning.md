# <G> - 6. Latent Preference Alignment & Online Learning

This note addresses the alignment extension: how the Two-Stage Architecture incorporates human preferences by modeling each human via a **high-level latent preference vector $z \in \mathbb{R}^p$ learned on the fly**, formalizing how personal alignment is achieved in state-of-the-art AI literature without corrupting the mathematical decision controller.

---

### 1. Motivation: Why Global RLHF Fails for Tutoring

Standard post-training alignment (Global RLHF / DPO) fits a single reward model $R(x, y)$ representing an "average" human:
* **The Failure Mode:** Humans possess fundamentally disparate learning preferences. Some learners desire maximum conciseness and resent verbose explanations; others require reassuring encouragement; some have high tolerance for Socratic struggle, while others experience rapid cognitive fatigue.
* A single reward model collapses to the average or degenerates into sycophancy (eagerly giving away the answers to maximize instantaneous approval).

---

### 2. The Latent Preference Representation $z \in \mathbb{R}^p$

Rather than hardcoding ad-hoc categorical flags (like "verbosity = high"), modern steerable alignment (e.g., *Pluralistic Alignment*, Anthropic Persona Vectors, Lin et al. 2024) models each user by a continuous **latent preference vector**:
$$ z \in \mathcal{Z} \subset \mathbb{R}^p $$

Let $\Phi(y) \in \mathbb{R}^p$ be a feature representation of the generated text advice $y$ across $p$ semantic axes:
* $\phi_1(y)$: Socratic friction / cognitive demand (open inquiry vs. closure).
* $\phi_2(y)$: Lexical density / conciseness (tokens per information unit).
* $\phi_3(y)$: Conversational warmth vs. clinical formality.
* $\phi_4(y)$: Scaffolding explicitness (subtle hints vs. overt structural analogies).

The subjective preference utility experienced by a user with latent vector $z$ when reading text $y$ is:
$$ R(y; z) = \langle \Phi(y), \; z \rangle = \sum_{i=1}^p z_i \phi_i(y) $$
* Positive $z_i$ indicates affinity for attribute $i$; negative $z_i$ indicates aversion or friction.

---

### 3. Stage 2 Formulation: Constrained Preference Alignment

Recall that Stage 1 (The Mathematical Controller) outputs the optimal control tuple:
$$ M_t^* = \big(\alpha_t^*, \; a_t^*, \; \hat{k}_t^*\big) $$
Stage 2 (The Verbalizer) must generate natural language text $y_t$ that simultaneously:
1. **Satisfies the Pedagogical Constraints:** Faithfully reflects the target scaffolding degree $\alpha_t^*$ and attention focus $a_t^*$.
2. **Maximizes Latent User Alignment:** Aligns the linguistic style with the user's estimated preference vector $\hat{z}_t$.

#### The Optimization Formulation
$$ \max_{y \in \mathcal{V}^*} \langle \Phi(y), \; \hat{z}_t \rangle \quad \text{s.t.} \quad \begin{cases} \mathcal{S}_{\text{scaffold}}(y) = \alpha_t^* \\ \mathcal{S}_{\text{attention}}(y) = a_t^* \\ \mathcal{S}_{\text{action}}(y) = \hat{k}_t^* \end{cases} $$
where $\mathcal{S}(\cdot)$ are semantic evaluation functions measuring the pedagogical fidelity of the generated text.

---

### 4. Learning the Latent Vector $z$ on the Fly (Online Bayesian Inference)

The user is never asked to fill out an explicit preference survey. Instead, the platform infers $z$ dynamically from **natural interaction telemetry**.

```
[ User Interaction Signals at Round t ]
- Dwell time / reading latency per token:  Δτ_t
- Conversational pushback / re-prompts:     r_t (e.g. "Just tell me the rule")
- Direct action compliance vs override:     y^_t
                           │
                           ▼
┌────────────────────────────────────────────────────────────────────────┐
│  BAYESIAN RECURSIVE UPDATER                                            │
│  Prior:       z_(t-1) ~ 𝒩(μ_(t-1), Σ_(t-1))                            │
│  Observation: f_t = Φ(y_t)^T z + ε_t,   ε_t ~ 𝒩(0, σ_f^2)              │
│  Posterior:   z_t | f_(1:t) ~ 𝒩(μ_t, Σ_t)                              │
└──────────────────────────┬─────────────────────────────────────────────┘
                           │
                           ▼
                  Mean Estimate: ẑ_t = μ_t
                           │
                           ▼
           Steers the Next Verbalizer Prompt
```

#### The Feedback Likelihood Model
At round $t$, the user's implicit satisfaction signal $f_t \in \mathbb{R}$ is extracted from telemetry:
$$ f_t = \Phi(y_t)^\top z + \epsilon_t, \qquad \epsilon_t \sim \mathcal{N}(0, \sigma_f^2) $$
* **Positive feedback ($f_t > 0$):** Smooth reading latency, immediate engagement with the Socratic hint, no re-prompting.
* **Negative feedback ($f_t < 0$):** Premature abandonment, angry follow-up prompt, high friction latency.

#### Recursive Kalman / Bayesian Update
Starting from a standard uninformative Gaussian prior $z_0 \sim \mathcal{N}(\mu_0, \Sigma_0)$:
$$ \Sigma_t^{-1} = \Sigma_{t-1}^{-1} + \frac{1}{\sigma_f^2} \Phi(y_t) \Phi(y_t)^\top $$
$$ \mu_t = \Sigma_t \left( \Sigma_{t-1}^{-1} \mu_{t-1} + \frac{1}{\sigma_f^2} f_t \Phi(y_t) \right) $$

**Sample Complexity:** Because the preference dimension $p$ is small (typically $p \in [3, 6]$), $\hat{z}_t = \mu_t$ converges rapidly within $t \in [3, 8]$ rounds, allowing the LLM to personalize its communication style during the diagnostic phase before graduation.

---

### 5. Practical Implementation via In-Context Prompt Steering

How does an out-of-the-box LLM (Gemini, Claude, GPT-4) execute this without weight fine-tuning?

The estimated vector $\hat{z}_t = [\hat{z}_1, \dots, \hat{z}_p]^\top$ is compiled into **latent steering instructions** in the prompt context:

```json
{
  "mathematical_constraints": {
    "scaffolding_degree_alpha": 0.0,
    "focus_features": ["Feature 1 (Temporary State)"],
    "action_prescription": "DO_NOT_REVEAL"
  },
  "latent_style_steering": {
    "density_preference": "HIGH_CONCISENESS (z2 = +1.4)",
    "friction_tolerance": "LOW_STRUGGLE (z1 = -0.9: provide gentle scaffolding hints)",
    "tone_preference": "INFORMAL_ENCOURAGING (z3 = +0.8)"
  }
}
```

#### Example Verbalizer Output under Different Latent Vectors $\hat{z}$:

* **User A (Prefers extreme brevity, high technical comfort):**
  > *"Compare feature 1 (state) vs essence. Which verb aligns?"* (10 words).
* **User B (Prefers reassuring narrative, low cognitive struggle):**
  > *"Take a look at how coldness is a temporary condition right now rather than an eternal trait of the dish. What does that suggest about whether to use 'ser' or 'estar'?"* (33 words, guided framing).

Both responses maintain the exact same mathematical control parameters ($\alpha_t^* = 0, a_t^* = e_1$), ensuring **zero compromise of the mathematical regret bounds** while maximizing individual user alignment.
