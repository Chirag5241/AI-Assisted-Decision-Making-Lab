We now find the optimal curriculum allocation to minimize the expected graduation loss.

During the training phase ($t = 1, ..., T$), $\mathcal{A}$ must determine the exposure vector $m = (m_1, ..., m_n) \in \mathbb{N}^n$ or the number of times to show each feature, satisfying $\sum_{j} m_j = T$. 

The perceived value difference contracts to the true difference by the dynamic:
$$ p_j(m_j) = (1 - \psi(m_j)) d_j + \psi(m_j) p_j^{(0)}$$

By [[2. Test Selection]], for $t > T$ the human picks the $F^*(p(m)) \subseteq [n]$ with $|F^*| \le c$ that maximizes perceived Value of Information:
$$ F^*(p(m)) = \arg\max_{|F| \le c} p_F(m)^\top \Gamma_{FF} p_F(m) $$
By [[3. Graduation Regret]], the expected regret incurred is:
$$ \mathcal{L}_{\text{grad}}(p(m)) = \sqrt{\frac{d^\top \Sigma d}{2\pi}} \Big( 1 - \rho\big(F^*(p(m)), p(m)\big) \Big) $$
where the Pearson correlation coefficient is:
$$ \rho\big(F^*(p(m)), p(m)\big) = \frac{d^\top (\Sigma - \Gamma) p(m) + p_{F^*}(m)^\top \Gamma_{F^*, :} \, d}{\sqrt{d^\top \Sigma d} \;\; \sqrt{p(m)^\top (\Sigma - \Gamma) p(m) + p_{F^*}(m)^\top \Gamma_{F^* F^*} p_{F^*}(m)}} $$

Since $\sqrt{\frac{d^T \Sigma d}{2\pi}}$ is constant, minimizing the expected regret is equivalent of maximizing the Pearson correlation coefficient.

Thus $\mathcal{A}$ must solve the following bilevel optimization problem, to find the optimal exposure vector to minimize the expected graduation loss:
$$
\begin{aligned}
\max_{m \in \mathbb{N}^n} \quad & \rho\big(F^*(p(m)), p(m)\big) \\
\text{subject to} \quad & \sum_{j=1}^n m_j = T, \quad m_j \in \mathbb{N} \\
& F^*(p(m)) = \arg\max_{|F| \le c} p_F(m)^\top \Gamma_{FF} p_F(m)
\end{aligned}
$$
Since $\rho(F, p)$ is discontinuous and non-linear, this is not a straightforward optimization problem and can't be reduced to knapsack or greedy.

We instead solve this through iterating over possible optimum/final feature sets which $\mathcal{H}$ can select, and find the maximizing Pearson correlation coefficient over these.

**Definition:** The salience of feature set $F$ of size $c$ is $S(F; p) = p_F^T \; \Gamma_{F, F} \; p_F$ , representing the perceived importance of $F$.

Let $\mathcal{F}_c = \{F \subseteq [n]: |F| = c\}$ be the candidate final feature sets of size $c$. Here, $|\mathcal{F}_c| = \binom{n}{c}$ is $O(n^c)$. Feature set $F^* \in \mathcal{F_c}$ is selected at graduation by $\mathcal{H}$ if $S(F^*; p(m)) > S(F; p(m))$ for all $F \in \mathcal{F_c} \setminus \{F^*\}$.

Fix $F \in \mathcal{F_c}$ with those features having exposure counts $m_{F} := \{m_j : j \in F\}$. For this to be selected at graduation by $\mathcal{H}$ (or have maximum value of information): $$S(F; p_F(m_F)) = p_F(m_F)^T \Gamma_{FF} p_F(m_F) > p_{F'}(m_{F'})^T \Gamma_{F' F'} p_{F'}(m_{F'})$$
for all $F' \in \mathcal{F_c} \setminus \{F\}$.  

We define the minimum cost of extinguishment as the minimum number of times the remaining features $j \not\in F$ be observed such that feature set $F$ with exposure counts $m_j$ be finally selected:
$$ \kappa(F, m_F) := \min_{m : \sum_j m_j \leq T\\ m_j = (m_F)_j \text{ for } j \in F } \Big\{\sum_{k \not\in F}m_k : \max_{F' \neq F} \big\{ p_{F'}(m_{F'})^T \Gamma_{F' F'} p_{F'}(m_{F'})\big\} < S(F; p_F(m_F)) \Big\}$$
For a fixed $F, m_F$, this can be computed in $O(T^c n^c)$ time. 
Thus a candidate feature set $F$ with exposure counts $m_F$ is realizable for training time budget $T$ iff: $\sum_{j \in F} m_j + \kappa(F, m_F) \leq T$. 

Let $m'$ be the exposure count vector minimizing the expression above. For any surplus exposure count remaining: $T_{\text{rem}} = T - \sum_{j} m_j$, we should only allocate it to features $j \in F$, since $F$ is the feature subset which will be chosen and hence be impacting the expected loss. We can then greedily allocate the remaining $T_\text{rem}$ to features $j \in F$ maximizing the correction gain: find $j^* = \arg\max_{j \in F} \Big[ \rho(F, p(m + e_j)) - \rho(F, p(m))\Big]$ and update $m_{j^*}' \leftarrow m_{j^*}' + 1$. Repeating this $T_\text{rem}$ times takes $O(cT)$ time.

**Algorithm:**
For each $F^* \in \mathcal{F}_c$ and feasible exposure count $m_{F^*}$, with $\sum_{j \in F^*} m_j \leq T$, compute $\kappa(F^*, m_{F^*})$ where $m$ is the allocation vector (over all features) attaining the minimum. 
If the feature set $F^*$ is feasible, or $\sum_{j \in F} m_j + \kappa(F, m_F) \leq T$, then $T_{\text{rem}} = T - \sum_j m_j$. 
We can then distribute the remaining $T_\text{rem}$ surplus via the greedy feature selection above. 
This gives us the final allocation vector $m^*$. Compute and store the Pearson correlation coefficient for this term: $\rho(F^*, p(m^*))$ We output the $m^*$ maximizing $\rho(F^*, p(m^*))$ over all the computed $F^*, m^*$. 

*Runtime:* Iterating over each $\mathcal{F}_c$ takes $O(n^c)$ time and there are $O(T^c)$ initial exposure vectors. Computing $\kappa(F, m)$ takes $O(n^c T^c)$ and the greedy distribution algorithm for remaining surplus takes $O(cT)$ time. Thus the total time to find the optimal exposure vector takes $O((nT)^{2c})$ time, which is polynomial in $n$ and $T$, for constant $c$.
