We now consider the case where losses incurred during training impact the overall loss. 

Here, $\mathcal{A}$ must pick a sequence of features $\pi = (F^{(1)}, ..., F^{(T)})$ to minimize the following objective, for $\lambda > 0$ and $\delta \in (0, 1)$:
$$ 
\mathcal{L}(\pi) := \lambda \sum_{t=1}^T \mathbb{E}\big[\ell_{\text{reg}}(x^{(t)}, \hat{y}_t)\big] + \sum_{t > T} \delta^{(t-T)} \mathbb{E}\big[\ell_{\text{grad}}(x^{(t)}, s^{(t)}; H^{(T)})\big]\\
$$
From [[3. Graduation Regret]], we know that the expected graduation loss has closed form: $\mathbb{E}\Big[ \ell_{\text{grad}}(x, s; H^{(T)})\Big] = \sqrt{\frac{d^\top \Sigma d}{2\pi}} \Big(1 - \rho\big(F^*(p), p\big)\Big)$. Thus we can rewrite:
$$ 
 \mathcal{L}(\pi) = \lambda \sum_{t=1}^T \ell_{\text{train}}\big(x^{(t)}, F_t; p^{(t)}\big) \;+\; \frac{\delta}{1-\delta} \sqrt{\frac{d^\top \Sigma d}{2\pi}} \Big(1 - \rho\big(F^*(p), p\big)\Big)
$$
where $F^*(p) = \arg\max_{|F| \le c} p_F^\top \Gamma_{FF} p_F$. 

For feature set $F \subseteq [n]$ with $|F| \leq c$, the perceived difference of value between action 1 and action 2 is $V(F, x_F, s; p) = p^T\mu(s) + p_F^T(x_F - \mu_F(s))$. 
This aligns with the correct move when $(d^T x) \cdot V(F, x_F, s; p) > 0$. 

**Definition:** For state $x$ and observation $s = Bx$ with perceived difference vector $p$, the <u>zero-regret set</u> $Z(x, s; p)$ is the collection of feature subsets of size at most $c$ such that the observation guarantees correct decision on $x$:
$$ Z(x, s; p) := \Big\{ F \subseteq [n], |F| \leq c : \big(d^T x\big) \cdot \big(p^T\mu(s) + p_F^T(x_F - \mu_F(s))\big) > 0 \Big\}$$

For state $x$ with observation $s$, we can see that if $\mathcal{A}$ shows any feature set $F \in Z(x, s; p)$, then the immediate loss incurred is $\ell_{\text{train}}(x, F; p) = 0$, since $\mathcal{H}$ will pick the correct move. Also, for each $j \in F$, the $p_j$ will contract closer to $d_j$.
